  2. Hier die E-Mail-Adressen eintragen (durch Komma getrennt, max. 5). Weitere Personen kannst du später auch in der App hinzufügen.
  1. Im Supabase-Dashboard unter SQL Editor das folgende SQL einfügen und ausführen.

  3. Oben im Projekt auf Connect klicken (oder Project Settings → Data API / API Keys) und die Project-URL sowie den publishable- bzw. anon-Key kopieren.
